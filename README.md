# Dual-Axis Learning Composer

A single-page React prototype for composing museum-education learning paths across cognitive depth and knowledge accessibility.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite, usually `http://127.0.0.1:5173`.

## Prototype notes

- All data is mocked locally in `src/main.jsx`.
- No backend or external API calls are required.
- The slide copy and image-generation prompt vary deterministically through local state.
- Tailwind is used for layout and styling through `src/styles.css`.
